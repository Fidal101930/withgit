# Student Grades SQL Project

This project is a simple Python and SQLite-based application for managing and working with student grade data.

## 📁 Project Files

- `app.py` - Main Python application
- `create_dp.py` - Creates and initializes the SQLite database
- `student_grades.db` - SQLite database containing student grade data
- `README.md` - Project documentation

## 🛠️ Technologies Used

- Python
- SQLite
- SQL
- Streamlit
